# soot

warm dark color scheme for [Ghostty](https://ghostty.org) terminal.

## palette

![soot color palette](palette.svg)

## installation

copy `soot.conf` to your Ghostty themes directory:

```sh
cp soot.conf ~/.config/ghostty/themes/
```

then add to your Ghostty config:

```
config-file = "themes/soot.conf"
```
